# SOUNDSONG

SOUNDSONG adalah aplikasi pemutar musik berbasis Flutter yang memungkinkan pengguna mencari lagu, melihat informasi lagu, memutar cuplikan audio, dan menyimpan lagu favorit.

## Fitur
- Pencarian lagu menggunakan iTunes Search API.
- Menampilkan informasi lagu dan artis.
- Memutar cuplikan audio lagu.
- Menyimpan lagu favorit di Library.
- Navigasi Home, Search, dan Library.
- Tampilan dengan tema gelap dan terang.

## Teknologi
- Flutter
- Dart
- iTunes Search API

## Menjalankan Aplikasi
1. Pastikan Flutter dan Dart sudah terpasang.
2. Clone repository ini.
3. Buka terminal di folder proyek.
4. Jalankan `flutter pub get`.
5. Jalankan `flutter run`.
